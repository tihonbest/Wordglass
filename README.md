# Wordglass
Wordglass — персональный тренажёр английских слов. Создавай собственные словари, учи слова с помощью карточек, проходи тесты и проверяй знания. Отслеживай прогресс, повторяй сложные слова и постепенно расширяй словарный запас. Минималистичный дизайн, автоматическое сохранение и поддержка офлайн-режима.
