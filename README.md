# Wordglass

**Wordglass** --- персональный тренажёр английских слов. Создавайте
собственные словари, учите слова с помощью карточек, проходите тесты и
проверяйте знания. Отслеживайте прогресс, повторяйте сложные слова и
постепенно расширяйте словарный запас.

🌐 **Открыть сайт:** https://tihonbest.github.io/Wordglass/

## Возможности

-   Создание собственных словарей без ограничения количества слов.
-   Три режима обучения: карточки, квиз с четырьмя вариантами ответа и
    письменная проверка перевода.
-   Учебные сессии до 10 слов.
-   Повторение слов, которые ещё не выучены или вызывают затруднения.
-   Индивидуальный и общий прогресс по словарям.
-   Автоматическое сохранение словарей и результатов на устройстве.
-   Минималистичный интерфейс, плавные анимации и светлый дизайн.
-   Поддержка установки на главный экран iPhone и iPad и офлайн-режима
    после загрузки необходимых файлов.

## Как добавить слова

Создайте словарь и добавьте пары «английское слово --- перевод». Можно
использовать, например, такие форматы:

``` text
apple — яблоко
school, школа
book: книга
```

Каждую пару можно вводить с новой строки.

## Публикация на GitHub Pages

Сайт опубликован с помощью GitHub Pages. Если вы форкаете проект или
